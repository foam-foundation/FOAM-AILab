# FOAM-AILab

Hands-on material for learning how AI models are trained, built around
[FOAM](https://github.com/foam-foundation/foam3), from gradient descent and
backprop to fine-tuning a language model.

## What you'll learn

The guides build up step by step:

1. **Gradient descent** – how a model learns by minimizing a loss
2. **Backpropagation** – how gradients flow through a network
3. **Neural networks** – building and training models from scratch
4. **Language models** – how text models work and are trained
5. **Fine-tuning** – adapting a pretrained language model to a new task

## How it's organized

This repository is a FOAM application that you run to try out each example.
The step-by-step guides that explain the concepts and walk you through the
examples are in [`/doc`](doc/).

## Getting started

1. Install FOAM by following the [foam3 INSTALL guide](https://github.com/foam-foundation/foam3/blob/development/INSTALL.md).
2. Start the FOAM-AILab application (instructions coming soon).
3. Open the first guide in [`/doc`](doc/) and follow along in the running application.
