# FOAM-AILab Documentation

Everything you need to learn how AI models are trained with FOAM, from
gradient descent and backprop to fine-tuning a language model. This folder
holds all of the learning material, including tutorials, guides and
foundational concepts, much of it paired with examples you can run in the
FOAM-AILab application.
