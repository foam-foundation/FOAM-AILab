# Contributing to FOAM-AILab

Thanks for helping out!

## Licensing of contributions

By contributing, you agree that your contribution is licensed as follows:

- Documentation in `/doc` → [CC BY-NC-SA 4.0](LICENSE-CONTENT),
  with code snippets in the documentation also under the [Apache License 2.0](LICENSE-CODE)
- Everything else, including the application code → [Apache License 2.0](LICENSE-CODE)

## License headers

New source files should start with:

    /**
     * @license
     * Copyright 2026 FOAM Foundation and contributors
     * SPDX-License-Identifier: Apache-2.0
     * http://www.apache.org/licenses/LICENSE-2.0
     */

## How to contribute

1. Fork the repo and create a branch.
2. Make your changes, keeping documentation in `/doc`.
3. Open a pull request describing what you changed and why.
